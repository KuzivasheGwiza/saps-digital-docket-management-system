# Safe five-minute SAPS DDMS demonstration

**Use fictional identities and docket data only.** The university capstone was a prototype developed with Boxfusion collaboration; this is not an official SAPS live service.

1. **Context (30 seconds).** Explain the paper-based docket problems described by the capstone brief: missing records, delayed handoffs, weak visibility and incomplete traceability.
2. **Administration (75 seconds).** Demonstrate account creation, permissions or account-status management using fictional users.
3. **User (60 seconds).** Demonstrate login, profile management and password or session workflow in a sandbox.
4. **Docket Management (120 seconds).** Register a fictional docket, inspect its detail view, show status/validation checks and demonstrate the allocation flow.
5. **Architecture and learning (45 seconds).** Explain Angular → ASP.NET Core API → EF Core → SQL Server, and describe manual API testing with Swagger UI.

Record locally only after reviewing screenshots for real names, badge numbers, locations, private case descriptions, secrets and other personal or operational information. Do not demonstrate with real police records. Features outside these three subsystems belong to the team system and should not be presented as your individual work.
